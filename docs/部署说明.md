# 部署说明

> learn-sys · 领域知识个性化生成与多智能体协同决策系统（挑战杯赛题 XH-202630）
> 部署形态：本地部署，两个进程（后端 API + 前端 Web）+ 一个 SQLite 文件。检索全离线，只有调用大模型时才需要联网。
>
> 本文以 Windows 为例，面向没有命令行经验的用户：能用鼠标完成的都写成鼠标操作；必须敲命令的地方给出可直接复制的命令，并说明成功时长什么样。全部流程约 10 分钟（不含下载时间）。其他平台差异见文末。

## 全流程一览

```
准备：装三个工具（uv、Node.js、pnpm）
① 解压提交包          → 鼠标操作（源码+预构建数据库+测试数据已合一）
② 解压模型到源码目录   → 鼠标操作（仅实时教学需要；只看回放可跳过）
③ 重命名 .env.example → 鼠标操作 + 记事本（仅实时教学需要）
④ 安装依赖            → 一条命令（初始化可跳过：提交包自带预构建数据库）
⑤ 启动后端            → 一条命令（窗口保持开着）
⑥ 启动前端            → 三条命令（另开一个窗口）
（⑦ 导入演示会话：提交包自带 50 组会话，无需导入）
```

---

## 第 0 步：安装三个工具（只需做一次）

| 工具 | 用途 | 怎么装 |
|---|---|---|
| Node.js | 前端运行时 | 打开 <https://nodejs.org/>，下载 **LTS** 版，双击安装包，一路"下一步"装完（版本须 ≥ 20） |
| uv | Python 依赖管理器（会自动准备 Python 3.13，你不需要自己装） | 见下方命令 |
| pnpm | 前端依赖管理器 | 见下方命令 |

按键盘 `Win` 键，输入 `powershell`，回车，打开一个蓝底窗口（下文统称"终端"）。依次粘贴执行：

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"   # 安装 uv
npm install -g pnpm                                          # 安装 pnpm
```

> 如果第一条报"禁止运行脚本"，先执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，输入 `Y` 回车，再重跑。

装完**关掉终端、重新打开一个**（命令才会生效），输入下面三行验证，每行都显示版本号就齐了：

```powershell
uv --version
node --version
pnpm --version
```

**关于 LLM 密钥（可选）**：系统调用大模型需要自备一个 OpenAI 兼容接口的密钥（如 DeepSeek / OpenAI）。没有密钥也能完整体验：提交包自带预构建数据库（含 50 组历史会话），启动后直接"回放"全部教学过程，不碰大模型。

## 第 ① 步：解压提交包（鼠标操作）

在资源管理器中打开交付包：

1. 右键 `learn-sys-提交包.zip` → **全部解压缩** → 点"提取"。
2. 得到 `learn-sys` 文件夹。打开它，里面能看到 `api`、`core`、`data`、`web` 等子文件夹、`测试数据` 文件夹和 `pyproject.toml` 文件。
3. `data` 文件夹里已有 `knowledge.db`（预构建数据库，含全部 50 组历史会话）——解压即就绪，无需导入任何数据。

这个 `learn-sys` 文件夹就是**源码根目录**，后文所有操作都以它为基准。

## 第 ② 步：放置模型（鼠标操作）

1. 进入 `04-模型文件`，右键 `bge-m3.zip` → **全部解压缩**。
2. "目标位置"一栏，填入（或用"浏览"选中）**源码根目录**，即上一步的 `learn-sys` 文件夹。
3. 勾选"完成时显示提取的文件"，点"提取"。等待约 1 分钟（模型约 2.2GB）。

**校验点**：源码根目录下出现 `data\bge-m3\models--BAAI--bge-m3` 文件夹，且进入它的 `snapshots` 子目录能看到 `pytorch_model.bin`（或 `model.safetensors`）权重文件，才是真正放对了。压缩包里已带好 `data\` 层级，解压到源码根目录恰好到位，不用手动搬任何文件。

## 第 ③ 步：配置环境变量（重命名 + 记事本）

1. 显示文件扩展名：资源管理器顶部菜单 **查看 → 显示 → 勾选"文件扩展名"**（Windows 10 在"查看"选项卡勾选）。
2. 在源码根目录找到 `.env.example`，右键 → 重命名 → 改成 `.env`（把 `-example` 删掉）。
3. 右键 `.env` → 打开方式 → **记事本**。
4. **没有 LLM 密钥**：什么都不改，直接关闭。
   （文件里的 `sk-your-key-here` 是占位值，系统不会把它当成已接通——启动后页面会提示"未接通 LLM 服务"，属正常现象；回放与报告功能不受影响，直接继续下一步。）
   **有密钥**：修改开头三行（等号右边换成你自己的值）：

   ```
   LLM_BASE_URL=https://api.deepseek.com     ← 你的接口地址
   LLM_API_KEY=sk-xxxx                       ← 你的密钥
   LLM_MODEL=deepseek-v4-flash               ← 对应模型名
   ```

   使用 DeepSeek 时，把 `LLM_EXTRA_BODY={"thinking": {"type": "disabled"}}` 那行开头的 `#` 删掉（本系统所有调用都是 JSON 输出，思考模式只会拖慢响应）。
5. `Ctrl+S` 保存，关闭记事本。

## 第 ④ 步：打开命令窗口

在资源管理器里打开**源码根目录**，鼠标点一下顶部的地址栏，输入 `powershell`，回车。
会弹出一个终端窗口，且当前目录正好是源码根目录。这个窗口后文称为**后端终端**，从现在起不要关闭。

## 第 ⑤ 步：安装依赖并初始化（两条命令）

在**后端终端**里依次粘贴执行（粘贴后按回车）：

```powershell
uv sync
```

首次运行会联网下载 Python 3.13 和全部依赖（约 2GB），需要几分钟，看到一串 `+ 包名==版本` 且没有红色报错即完成。下载慢的解法见文末常见问题。

```powershell
$env:HF_HUB_OFFLINE = 1; uv run python scripts/init_db.py
```

约 1 分钟。**成功标志**：最后一行包含 `entries=49, vec=49, fts=49`（双领域 49 条知识条目：大数据工程 31 条 + Linux 运维 18 条，各带向量索引与全文索引）。该脚本幂等，可反复执行。
> **可跳过本条命令**：提交包解压后 `data/knowledge.db` 已自带（预构建库，含全部评测会话）——
> 只想看回放与报告的话直接进入第 ⑥ 步启动即可；重新初始化或清空数据时才需要跑上一步。
> 无向量模型 / 无 LLM 密钥时系统也能启动：页面顶部会显示缺什么、哪些功能受影响，回放与报告不受影响。

## 第 ⑥ 步：启动后端（不要关这个窗口）

继续在**后端终端**粘贴执行：

```powershell
$env:HF_HUB_OFFLINE = 1; uv run uvicorn api.main:app --port 8000
```

模型加载约 30 秒。看到 `Application startup complete` 后，窗口会停在那里不再滚动——这是正常的，表示服务正在运行。**这个窗口要一直开着**。

验收：浏览器打开 <http://localhost:8000/openapi.json>，看到一大段 JSON 文本即成功。

## 第 ⑦ 步：启动前端（另开一个窗口）

1. 在资源管理器里再次打开**源码根目录**，地址栏输入 `powershell` 回车，开一个新终端（下称**前端终端**；后端终端别关）。
2. 依次粘贴执行：

```powershell
cd web
pnpm install
pnpm build
pnpm start
```

`pnpm install` 约 1 分钟；看到 `Ready in ...` 和 <http://localhost:3000> 即启动成功。此窗口同样保持开着。

验收：浏览器打开 <http://localhost:3000>，看到首页（学习者画像表单）即成功。

## 第 ⑧ 步：导入演示会话（通常可跳过）

提交包解压后 `data/knowledge.db` 已自带全部 50 组历史会话，启动后直接可用，**此步可跳过**。
仅在需要"从测试数据包的 JSON 文件重新导入"时才执行：按第 ④ 步的方法开一个终端，在源码根目录执行：

```powershell
uv run python scripts/import_test_data.py
```

脚本会自动在源码内定位测试数据（`测试数据/02-会话示例`）。如果提示未找到，手动指定目录：

```powershell
uv run python scripts/import_test_data.py --data-dir ".\测试数据\02-会话示例"
```

（路径按你的实际位置调整，指向源码内的 `测试数据\02-会话示例` 文件夹即可。）

**成功标志**：最后一行显示 `50/50 组导入成功`。之后浏览器打开 <http://localhost:3000/sessions>，能看到 50 组历史会话。

## 体验路径

**无 LLM 密钥**（回放演示）：
会话列表 → 点进任意会话 → 裁判面自动进入回放模式（可切 1x/2x/4x 速度，重演多智能体协同决策全过程）→ 报告页查看三指标、知识盲区雷达、学习路径图和资源包。
推荐先看 **p10**（含打回重写与连错回退，协同决策中间数据最完整）和 **p47**（16 主题的代表会话）。

**有 LLM 密钥**（完整闭环）：
首页填写学习者画像 → 创建会话 → 学生面逐主题学习、作答 → 裁判面实时观察调度 → 结束会话 → 报告页。

## 停止与清理

- **停止服务**：直接关掉两个终端窗口即可。
- **清空数据重来**：在资源管理器里删除源码根目录下 `data\knowledge.db` 文件（鼠标操作），然后重跑第 ⑤ 步的两条命令；需要演示数据就再跑一次第 ⑧ 步。

## 常见问题

| 现象 | 原因与解法 |
|---|---|
| 提示 `uv` / `node` / `pnpm` 不是可识别的命令 | 工具没装，或装完没有重开终端。重开终端再试；仍不行回第 0 步重装 |
| PowerShell 报"禁止运行脚本" | 执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，输入 `Y` |
| 后端启动卡在模型加载、无报错 | 漏了 `$env:HF_HUB_OFFLINE = 1`。`Ctrl+C` 停止，按第 ⑥ 步的完整命令重来 |
| 8000 / 3000 端口被占用 | 换端口：后端改 `--port 8001`；前端执行 `pnpm start -- -p 3001`（改端口前需重新 `pnpm build`，因为前端 API 地址是构建时写入的） |
| `uv sync` 下载慢 | 先执行 `$env:UV_DEFAULT_INDEX = "https://pypi.tuna.tsinghua.edu.cn/simple"`，再重跑 `uv sync` |
| LLM 调用超时 | 系统内置 180 秒超时，超时会明确报错而不是卡死；检查 `LLM_BASE_URL` 是否能正常访问 |
| `pnpm build` 报 `EPERM: symlink` | 本版源码已移除触发该错误的配置；如仍遇到，开启开发者模式（系统设置 → 开发者选项）或以管理员身份运行终端后再构建 |

## macOS / Linux 差异（其他平台用户）

流程和界面操作（解压、重命名）一致，仅命令写法不同：

```bash
# uv 安装
curl -LsSf https://astral.sh/uv/install.sh | sh

# 解压
unzip 01-源码/learn-sys-源码.zip
cd <源码根目录> && unzip <交付包>/04-模型文件/bge-m3.zip

# 环境变量前缀写法（替代 $env:...）
HF_HUB_OFFLINE=1 uv run python scripts/init_db.py
HF_HUB_OFFLINE=1 uv run uvicorn api.main:app --port 8000

# 复制 .env
cp .env.example .env
```

下载慢时镜像写法：`export UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple`。

## 数据合规声明

系统使用的学习者画像均为程序生成的合成数据（`evals/gen_profiles.py`，固定种子可复现），不含任何真实个人信息；全部交互记录仅存储于本地 SQLite 文件（`data/knowledge.db`），无第三方上报。
