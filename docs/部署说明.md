# 部署说明

> learn-sys · 领域知识个性化生成与多智能体协同决策系统（挑战杯赛题 XH-202630）
> 部署形态：本地部署——两个进程（后端 API + 前端 Web）+ 一个 SQLite 文件，检索栈全离线，仅 LLM 调用需要网络。

## 1. 环境要求

| 组件 | 版本 | 安装方式 | 说明 |
|---|---|---|---|
| [uv](https://docs.astral.sh/uv/) | 最新 | `curl -LsSf https://astral.sh/uv/install.sh \| sh`（Windows：`powershell -c "irm https://astral.sh/uv/install.ps1 \| iex"`） | Python 依赖管理器；**会自动下载管理 Python 3.13，无需自行安装 Python** |
| Node.js | ≥ 20 LTS | [官网安装包](https://nodejs.org/) | 前端运行时 |
| pnpm | ≥ 9 | `npm install -g pnpm` | 前端依赖管理器 |
| LLM API | OpenAI 兼容协议 | — | 任意兼容接口（如 DeepSeek / OpenAI），自备 base_url + api_key |

推荐操作系统：Linux / macOS。依赖栈（torch CPU 轮子、sqlite-vec 等）对 Windows 亦有官方支持。
首次安装依赖需要联网（`uv sync` 约 2GB、`pnpm install` 约 300MB）；**运行期检索全离线**，仅访问 `LLM_BASE_URL`。

## 2. 交付包结构

```
提交压缩包/
├── 源码/                      # 仓库归档（含 data/seeds 知识种子）
├── 模型文件/bge-m3.zip        # BGE-M3 embedding 模型（约 2.4G，解压后约 4.5G）
├── 部署说明.md                # 本文档
├── 测试数据包/                # ≥3 组差异化画像的完整输入输出示例
└── （其余材料：设计实现方案 / 演示视频 / PPT / 报名表）
```

## 3. 部署步骤

以下命令均在源码根目录执行。

### 步骤 1：放置模型

将模型压缩包解压，使目录结构为：

```
源码根目录/
└── data/
    └── bge-m3/
        └── models--BAAI--bge-m3/     ← 校验点：此目录存在即放置正确
```

### 步骤 2：配置环境变量

```bash
cp .env.example .env
```

编辑 `.env`，填入你的 LLM 配置（任何 OpenAI 兼容接口）：

```bash
LLM_BASE_URL=https://api.deepseek.com     # 或你的接口地址
LLM_API_KEY=sk-xxxx                       # 你的密钥
LLM_MODEL=deepseek-v4-flash               # 对应模型名
```

> 使用 DeepSeek 时建议同时取消注释 `LLM_EXTRA_BODY={"thinking": {"type": "disabled"}}`——
> 本系统所有调用均为 JSON 输出，思考模式只增加延迟。

### 步骤 3：安装后端依赖并初始化知识库

```bash
uv sync                                   # 自动下载 Python 3.13 + 全部依赖
HF_HUB_OFFLINE=1 uv run python scripts/init_db.py
```

预期输出：知识条目加载成功（31 条）、会话表迁移完成。该脚本**幂等**，可反复执行。

> Windows 下 `HF_HUB_OFFLINE=1` 写法为 `set HF_HUB_OFFLINE=1 && uv run python scripts/init_db.py`（下文同理）。

### 步骤 4：启动后端

```bash
HF_HUB_OFFLINE=1 uv run uvicorn api.main:app --port 8000
```

BGE-M3 模型加载约 30-60 秒，看到 `Application startup complete` 即就绪。
验收：浏览器访问 `http://localhost:8000/openapi.json` 返回 API 文档 JSON。

### 步骤 5：启动前端

另开一个终端：

```bash
cd web
pnpm install
pnpm build && pnpm start                  # 生产模式；开发调试可用 pnpm dev
```

验收：访问 `http://localhost:3000` 看到首页（学习者画像表单）。

### 步骤 6：走通完整闭环（验收）

1. 首页填写/选择学习者画像 → 创建会话（诊断 + 课程切片）；
2. 学生面工作台：逐主题学习讲义、作答、查看追问；
3. 裁判面（会话列表进入）：实时观察多智能体协同调度；
4. 结束会话 → 报告页：三指标 + 知识盲区雷达 + 学习路径图 + 资源包浏览。

**无 LLM key 的环境**：系统支持历史会话回放（会话列表 → 回放入口），无需 LLM 即可演示完整教学过程。

## 4. 常见问题

| 现象 | 原因与解法 |
|---|---|
| 后端启动卡在模型加载、无报错 | sentence-transformers 联网探测 HuggingFace Hub 被墙——务必带 `HF_HUB_OFFLINE=1` 启动（模型已随包携带，无需联网） |
| 8000 / 3000 端口被占用 | 改端口：后端 `--port 8001`；前端 `pnpm start -- -p 3001`（前端需重新 `pnpm build`，API 地址为构建时内联变量） |
| 想清空全部会话数据重来 | 删除 `data/knowledge.db` 后重跑步骤 3（知识条目自动重建；评测历史会话一并清空） |
| `uv sync` 下载慢 | 为 uv 配置 PyPI 镜像：`export UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple` |
| LLM 调用超时 | 系统内置 180s 读取超时，超时会明确报错而非挂起；请检查 `LLM_BASE_URL` 可达性 |

## 6. 数据合规声明

系统使用的学习者画像均为程序生成的合成数据（`evals/gen_profiles.py`，固定种子可复现），不含任何真实个人信息；全部交互记录仅存储于本地 SQLite 文件（`data/knowledge.db`），无第三方上报。
