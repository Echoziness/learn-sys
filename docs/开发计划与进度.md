## 知识库生产 SOP（贯穿 Phase 2-4）

1. 按职业标准模块列条目清单（职业功能 → 工作内容 → 相关知识要求）；
2. AI 批量生成草稿（官方文档改写，禁复制）；
3. 脚本自动校验：schema 七字段齐全、prerequisites 指向存在条目、difficulty ∈ [1,5]；
4. 核心条目抽审 ≥10%（SQL/pandas 可执行示例当场运行验证）；
5. `init_db.py` 幂等入库即完成，无需任何代码改动。
