## Phase 1 — CLI 最简闭环

### 目标

一个 Python CLI 脚本，输入一份学习者画像 JSON，走完整链路：诊断→规划→混合检索→生成→审核，输出带溯源标注的学习资源，并打印审核结果。

### 涉及文件

```
core/
├── state.py          # AgentState + agent 间消息 Pydantic 模型
├── llm.py            # LLMProvider（显式注入）+ chat_validated 校验重试
├── retrieval.py      # Retriever：FTS5(CJK逐字切分) + sqlite-vec + RRF + 覆盖度判定
├── embedding.py      # BGEEncoder（仅组合根 import）
├── config.py         # Settings（唯一 env 读取点）
├── logging.py        # structlog JSON
├── graph.py          # diagnose → retrieve → generate → review 最小图
└── agents/
    ├── diagnose.py   # 画像输入 → 盲区知识点列表
    ├── generate.py   # 检索条目 + 画像摘要 → 带 evidence_ids 的生成稿
    └── review.py     # 生成稿 + 引用原文 → NLI 裁决（按条论断）
scripts/
├── run_cli.py         # Phase 1 CLI 入口（组合根，Phase 3 CLI 由 api/ 接管）
└── init_db.py         # 幂等 loader：data/seeds/ → 建表 + FTS5 + vec
data/
├── seeds/bigdata-analysis/entries.jsonl  # 种子条目（一等数据文件）
├── seeds/profiles/test1.json             # 示例画像
└── knowledge.db       # init_db.py 生成
tests/                 # pytest：FTS 转义/审核合并/指标口径/LLM 校验/init 幂等
evals/
└── metrics.py         # 幻觉率口径 SSOT
```
