## 1. 总览：四层模型

```
┌─────────────────────────────────────────────────────────────┐
│ 决策可视化层   web/ 裁判面（React Flow）+ 学生面 + 报告页      │ ← 体验/创新分载体
├─────────────────────────────────────────────────────────────┤
│ 会话服务层     api/（FastAPI 薄层）+ core/teach_loop 编排      │ ← 事件流生产/消费
├─────────────────────────────────────────────────────────────┤
│ 教学内核层     core/ agents + 纯函数（assess/mastery/plan）    │ ← 已完成，冻结打磨
│               + answer_pipeline + deliver（资源组装）         │
├─────────────────────────────────────────────────────────────┤
│ 数据层         SQLite 单文件（知识库 + 会话 + 资源包 + 事件流） │
└─────────────────────────────────────────────────────────────┘
```

运行态组件恒定：一个 Python 进程（api）+ 一个 Node 进程（web）+ 一个 SQLite 文件。

**依赖方向**：`web/ ─(SSE)→ api/ → core/ → data/`。core/ 不接触网络层；api/ 只做序列化→转发→推流；图在组合根编译一次。

## 2. 模块划分（core/ 扩展后全景）

| 模块 | 职责 | 状态 |
|---|---|---|
| `core/agents/*` | 六个 LLM/规则节点（见 PRD §4） | ✅ 冻结 |
| `core/assess.py` `core/mastery.py` `core/plan.py` | 出题/掌握度/切片纯函数 | ✅ 冻结 |
| `core/answer_pipeline.py` | 作答处理共用服务（CLI/Web 同入口） | ✅ |
| `core/graph.py` | 教学子图装配（retrieve→generate→review） | ✅ |
| `core/session.py` | **新增**：SessionStore——会话/事件/轮次/掌握度/资源包的 DB 读写 + 事件发射 | 🔨 W1 |
| `core/teach_loop.py` | **新增**：会话编排服务（诊断→切片→逐主题循环），CLI 与 Web 共用 | 🔨 W1（自 run_cli.py 抽取） |
| `core/deliver.py` | **新增**：资源包组装（纯函数：claims→讲义、题目归档、指南提取、进阶标记） | 🔨 W1 |
| `core/retrieval.py` `core/embedding.py` `core/llm.py` `core/config.py` `core/logging.py` | 基础设施 | ✅ |

**关键决策**：事件发射不进 agent 节点签名。节点保持 `(state, *, provider, model)` 不变；编排层（teach_loop）与 api 层消费 LangGraph `astream(stream_mode="updates")` 转换为 session 事件——core 内核零改动，CLI/Web 天然一致。

## 3. 数据模型（SQLite，全部幂等迁移）

### 3.1 既有表（不动）

`knowledge_entries`（含 FTS5/vec 外部表）、`learner_profiles`（种子画像，只读）。

### 3.2 新增表（W1，`scripts/init_db.py` 幂等迁移）

```sql
-- 会话元数据：画像快照 + 诊断结果 + 切片
CREATE TABLE IF NOT EXISTS sessions (
  session_id TEXT PRIMARY KEY,          -- uuid4hex
  learner_id TEXT NOT NULL,
  profile_json TEXT NOT NULL,           -- 输入画像完整快照
  gap_ids_json TEXT,                    -- 诊断收敛的本体条目 ID
  difficulty_level TEXT,                -- beginner/intermediate/advanced
  profile_summary TEXT,
  plan_json TEXT,                       -- 切片结果（含前置链）
  status TEXT NOT NULL DEFAULT 'active',-- active / finished / aborted
  created_at TEXT NOT NULL,
  finished_at TEXT
);

-- 统一事件流：裁判面渲染协议 + 回放媒体流 + 审计日志（一表三用）
CREATE TABLE IF NOT EXISTS session_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  seq INTEGER NOT NULL,                 -- 会话内单调递增，回放排序键
  event_type TEXT NOT NULL,             -- 见 §4 事件协议
  payload_json TEXT NOT NULL,           -- 自包含：前端仅凭 payload 可渲染
  created_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_events_session ON session_events(session_id, seq);

-- 教学轮快照：题目/作答/判分/决策的结构化中间数据（提交物"协同决策中间数据"）
CREATE TABLE IF NOT EXISTS topic_rounds (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  entry_id TEXT NOT NULL,
  round_no INTEGER NOT NULL,
  question_json TEXT,                   -- 题目（含题型、题干、选项；expected 单列）
  expected_json TEXT,                   -- 判分要点（不进学生视野）
  answer_text TEXT,
  grade_json TEXT,                      -- 规则覆盖率 + LLM verdict + evaluation + missed
  decision TEXT,                        -- advance / retry / regress / scaffold
  mastery_after REAL,
  created_at TEXT NOT NULL
);

-- 掌握度历史：报告曲线与跨会话延续
CREATE TABLE IF NOT EXISTS mastery_snapshots (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  learner_id TEXT NOT NULL,
  entry_id TEXT NOT NULL,
  round_no INTEGER NOT NULL,
  correctness INTEGER NOT NULL,         -- 0/1（脚手架答对不写入）
  mastery_after REAL NOT NULL,
  created_at TEXT NOT NULL
);

-- 资源包：三形态资源 + 溯源链（赛题主交付物）
CREATE TABLE IF NOT EXISTS resource_packages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  learner_id TEXT NOT NULL,
  entry_id TEXT NOT NULL,
  lecture_json TEXT,                    -- 讲义：审核通过论断 [{text, evidence_ids, claim_type, round}]
  questions_json TEXT,                  -- 分阶题：[{type: choice/scaffold/answer, prompt, options?, round}]
  practice_json TEXT,                   -- 实操指南：{steps, example, checkpoints}（procedure 条目）
  challenge_json TEXT,                  -- 进阶挑战任务（mastery≥0.85 时）
  difficulty_tier TEXT NOT NULL,        -- 资源难度层级（适配率指标的判定输入）
  created_at TEXT NOT NULL,
  UNIQUE(session_id, entry_id)
);
```

**不变量**：画像/本体只读（种子文件是事实源）；运行时只追加 sessions/events/rounds/snapshots/packages；DB 变更一律幂等迁移，禁止删库重建。

## 4. 事件协议（裁判面与回放的渲染指令集）

事件 = `(seq, event_type, payload)`，payload 自包含。类型清单：

| event_type | payload 要点 | 消费者 |
|---|---|---|
| `session_start` | 画像、learner_id | 学生面、裁判面 |
| `diagnose_done` | gap_ids、gaps 文本、difficulty_level、summary | 双面 |
| `plan_done` | 切片列表 [{entry_id, title, 序位}] | 双面（路径图初值） |
| `topic_start` | entry_id、round_no、retry 轮标记 | 双面 |
| `retrieve_done` | queries、命中条目 [{id,title,score}]、uncovered | 裁判面（检索面板） |
| `generate_done` | claims 数、cited_entries | 裁判面（节点脉冲） |
| `review_done` | 逐条裁决 [{claim_index, verdict, reason}]、unsupported 数、轮次 | 裁判面（打回回路主画面） |
| `teach_delivered` | 最终论断全文（含 evidence_ids、claim_type） | 学生面（讲义正文）、裁判面（溯源侧栏） |
| `question_built` | 题型、题干、选项（无 expected） | 学生面出题卡 |
| `answer_graded` | 规则覆盖率、verdict、evaluation、missed_requirements、decision、mastery_after | 双面（反馈卡 + 决策节点） |
| `scaffold_offered` | 题干、镜像干扰项来源说明 | 双面 |
| `topic_advance` / `topic_regress` | entry_id、目标条目、原因（连错/达标） | 裁判面（路径图推进/回边） |
| `package_saved` | entry_id、三形态资源就绪标记、进阶挑战标记 | 报告页、资源总览 |
| `session_end` | 汇总统计（主题数、轮次、最终 mastery 汇总） | 报告页 |

**实时与回放同构**：实时会话中 api 边执行边写 `session_events` 并推 SSE；回放模式 `GET /replay` 按 seq 重放同一流，前端渲染代码完全复用——评委无 LLM key 环境的可演示保障。

## 5. API 契约（薄层，业务全部在 core）

| 端点 | 方法 | 职责 |
|---|---|---|
| `/api/sessions` | POST | 建会话：画像 → 诊断 + 切片 → 持久化，返回 session_id + plan |
| `/api/sessions/{id}/topics/{entry}/teach` | POST | 执行教学子图，SSE 推 §4 教学事件，终帧为 teach_delivered |
| `/api/sessions/{id}/topics/{entry}/question` | POST | 出题（choice 确定性 / answer 走 question 节点），SSE 单帧 |
| `/api/sessions/{id}/answers` | POST | 作答 → answer_pipeline 判分 → 决策 + 资源沉淀，SSE 推判分与决策事件 |
| `/api/sessions/{id}/report` | GET | 报告数据：盲区雷达 / 难度匹配 / 路径（含回边） |
| `/api/sessions/{id}/resources` | GET | 资源包列表（三形态 + 溯源链） |
| `/api/sessions/{id}/replay` | GET | 历史事件流重放（SSE） |

约束：请求/响应 Pydantic 模型在 `api/models.py`；SSE 帧 = JSON 序列化的 session 事件 + `event:` 类型行；每端点有 exception handler 兜底（LLM 失败返回结构化错误事件，不静默）。

**运行时装配**：api 启动时创建 provider / encoder / retriever / 编译图并常驻（BGE-M3 约 2GB，进程生命周期内只加载一次）；会话状态从 DB 重建，api 无内存会话态。

## 6. 会话状态机（教学轮）

```
topic_start ─→ teach（子图：retrieve→generate→review，打回≤3）
            ─→ question（choice | scaffold | answer，floor 单向推进）
            ─→ answer ─→ grade（规则预筛 → LLM 复核 → 题意核对硬收口）
                     ├─ advance ─→ package_saved ─→ 下一 topic（或 session_end）
                     ├─ retry   ─→ topic_start(round+1, retry_context 注入)
                     ├─ regress ─→ 前置 topic 的 topic_start
                     └─ scaffold_pending ─→ question(scaffold) ─→ 回 answer
```

决策由 `core/mastery.decide_next_step` 纯函数裁决；编排状态机在 `core/teach_loop.py`，CLI 与 Web 共用。

## 7. 上下文隔离矩阵（agent 读写权限 SSOT）

唯一事实源为 `AGENTS.md` §3.5 节点表（diagnose/retrieve/generate/review/question/feedback/answer_pipeline 的读写 key 清单）。红线重申：review 零画像字段；generate 只读 profile_summary；对话日志永不进生成上下文；expected 永不进学生视野（裁判面可见——审计视角）。越界即 code review 驳回。

## 8. 关键机制实现索引

| 机制 | 位置 | 一句话 |
|---|---|---|
| 分层审核 | `core/agents/review.py` | core 逐字支持 / extension 概念一致；merge_verdicts 纯函数 unsupported 优先 |
| 判分级联 | `core/answer_pipeline.py` | 规则预筛 → LLM 复核 → missed 硬降级 → fail-closed |
| 题型阶梯 | `core/assess.py` | 掌握度驱动 + floor_type 单向推进 + 脚手架状态机 |
| 深度契约 | `core/agents/question.py` | taught_claims 为出题上限；retry 缓存失效 |
| 资源组装 | `core/deliver.py`（W1） | 审核通过论断 + 归档题目 + 指南提取 + 进阶标记 |
| 事件流 | `core/session.py`（W1） | 写 DB + SSE 订阅推送；回放同构 |
| 回放 | `api/routes/` | 按 seq 重放 session_events |

## 9. 部署形态

docker compose 三服务：`api`（uvicorn + BGE 常驻）、`web`（Next.js standalone）、`db-init`（init_db 幂等迁移，跑完退出）；SQLite 文件挂卷。LLM key 通过环境变量注入；无 key 环境走回放模式演示。
