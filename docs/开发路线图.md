## 5. 风险与预案

| 风险 | 概率 | 预案 |
|---|---|---|
| 幻觉率实测超标（>5%） | 中 | W2.3 第一天小批跑；调 generate 证据锚定与 review 严格度，重跑验证 |
| Web 工作量失控 | 高 | 裁判面降级为时间线；报告页三图砍为两图；学生面优先保闭环 |
| LLM 供应商抖动 | 中 | 回放模式兜底（W1 地基 + W2.7）；评测支持断点续跑 |
| 评测跑批时长 | 低 | 50 组 × ~30 调用，并发压到 30 分钟内；deepseek flash 成本可忽略 |
| 会话持久化迁移踩坑 | 低 | 幂等迁移已验证过一次（knowledge_type）；新表全部 CREATE IF NOT EXISTS |

## 6. 每周验收纪律

- 周五晚对照本文验收栏逐项打勾，未达项周六补，周六仍不过则砍范围不延周；
- 验收 = 运行产物（DB 记录 / 指标 JSON / 页面截图），不是"代码写完了"；
- 全程 pytest + pyright + ruff 三绿才算任务完成（现有 120 测试为回归基线）。
