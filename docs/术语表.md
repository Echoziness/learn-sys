# 术语表

> **版本**：v1.0 · 2026-07-22
> **文档类型**：Glossary — 跨文档命名一致性的唯一事实源。PRD / 架构文档 / 代码中出现术语时，必须与此表对齐。

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 会话 | Session | 一次完整的 diagnose → learn → assess → feedback 的运行周期 |
| 教学主题 | Topic | 一个诊断出的知识盲区，对应知识库中的一个或一组条目 |
| 教学单元 | Teaching Unit | "讲一段 → 检验题 → 判对错 → 决定下一步" 的最小交互周期 |
| 教学策略 | Strategy | 讲授方式：`direct_instruction` / `scaffolding` / `socratic` / `guided_practice` / `challenge` |
| 题型 | Question Type | 检验方式：`choice`（选择题）/ `open`（问答题）/ `practice`（操作题） |
| 掌握度 | Mastery | 学习者在每个知识点上的 0.0-1.0 得分，由 EMA(α=0.3) 持续更新 |
| 知识条目 | Entry / Knowledge Entry | 知识库中一条带 id / title / content / prerequisites / difficulty / source 的记录 |
| 论断 | Claim | generate 产出的一段教学内容，必须挂 `evidence_ids` |
| 裁决 | Verdict | review 输出的判断：`supported` / `partially_supported` / `unsupported` |
| 打回 | Retry / Strike Back | review 发现论断有未支持部分时，路由回 generate 重写的过程 |
| 降级 | Degrade | 辩论超 3 轮未全部通过时，仅保留 supported 论断重组交付 |
| 降维 | Regression / Remediation | 学生答题正确率过低时，回到更低难度条目重新讲授 |
| 难度闸门 | Difficulty Cap | 检索时的 `max_difficulty` 过滤——初学者只看难度 1-2 条目 |

> **同步规则**：新增/修改术语时，必须同时检查 PRD 和 AGENTS.md 中对应的用词。
