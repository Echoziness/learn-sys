## 会话与课程

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 会话 | Session | 一次完整的 diagnose → plan → 逐主题教学 → 收尾的运行周期 |
| 教学主题 | Topic | 课程切片中的一个教学单元，锚定知识库一个条目（entry） |
| 教学轮 | Round | 同一主题内的一次"教学 → 出题 → 作答 → 判分 → 决策"周期 |
| 课程切片 | Plan / Slices | `core/plan.py` 纯函数：gap 投影到本体 ID + 前置链闭包 + 难度过滤 + 拓扑排序的产物 |
| 本体 | Ontology | 知识条目的静态集合（data/seeds/），教学执行层永不反向修改 |
| 降维 | Regress | 连续答错达到阈值时，回到前置主题重新讲授（`decide_next_step` 的 regress 分支） |
| 教学领域 | Domain | `data/seeds/<域>/` 子目录对应的知识本体（如 bigdata-analysis / linux-ops）；会话建时自选，诊断/检索/教学/资源全链路同域隔离（2026-08-28） |
| 困惑记录 | Followup Record | 学生主动提问经判定有效后落的侧车轮记录（topic_rounds，question_type='followup'，answer 承载系统解答）；未消化时注入下一轮教学（`followup_context`），并进误区提炼原料（2026-08-28 设计回归） |

## 题型与判分

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 题型 | Question Type | 仅两种：`choice`（选择题，识别式）/ `answer`（回答题，回忆式），与知识类型解耦、由掌握度驱动 |
| 题型单向推进 | Floor Type | 进入 answer 深度后不因单次失误降回 choice；`build_question(floor_type=...)` 强制 |
| 判分要点 | expected / expected_keywords | answer 题的服务端判分依据，与题干一起由 LLM 生成，字符必须出自条目 content（服务端校验） |
| 覆盖率 | Coverage | 学生作答覆盖 expected 关键词的比例；规则预筛阈值 0.6 |
| 规则预筛 | Rule Pre-screen | `core/assess.py` 的确定性判分：choice 认选项标签，answer 算关键词覆盖率 |
| LLM 复核 | LLM Review | `core/agents/feedback.py`：规则放行后的概念级复核 + 教学评估 |
| 评估与裁决分离 | — | answer 题总是送 LLM 评估（低覆盖率作答最有教学价值）；规则只降级裁决不降级评估 |
| fail-closed | — | 无证据即判错的收口原则：LLM 缺席回退规则时要求覆盖率 1.0；LLM 判对但覆盖率 <0.6 维持判错 |
| 题意核对 | Requirement Check | feedback 强制拆"题目要求检查单"输出 `missed_requirements`；判对但遗漏清单非空 → 服务端硬降级 partial |
| 脚手架选择题 | Scaffold Choice | answer 失败后下一轮的过渡题：干扰项镜像学生错误理解，答对回 answer 但不计入掌握度历史 |

## 掌握度

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 掌握度 | Mastery | 0.0-1.0 的知识点得分，`core/mastery.py` 纯函数唯一事实源 |
| recency 加权 | Recency Weights | 最近 5 次作答按新旧加权 (0.5, 0.7, 0.85, 0.95, 1.0)，早期失误后的恢复被补偿 |
| 置信度封顶 | Confidence Cap | 作答次数不足时的掌握度硬上限：1 次 0.5、2 次 0.8——防"碰巧答对即通关" |
| 掌握门槛 | MASTERY_GATE | 0.7，`is_mastered` 的硬裁决线 |
| 连错降维阈值 | REGRESS_AFTER_CONSECUTIVE_WRONG | 连续答错 2 次触发 regress |
| 轮次上限 | MAX_ATTEMPTS_PER_TOPIC | 单主题 5 轮，超限按部分掌握放行（防死循环） |

## 生成与审核

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 论断 | Claim | generate 产出的一段教学内容，schema 强制挂 `evidence_ids`（非空） |
| 论断分层 | claim_type | `core`（条目覆盖层，严格证据链）/ `extension`（错因扩展层，仅重教轮，审核降为"概念一致+推导自洽"） |
| 裁决 | Verdict | review 对每条论断的 NLI 三分类：`supported` / `partially_supported` / `unsupported` |
| 打回 | Retry | review 发现未支持论断时路由回 generate 重写（教学子图内，轮次上限 3） |
| 降级 | Degrade | 辩论超 3 轮未全通过时仅保留 supported 论断重组交付 |
| 错因回流 | Retry Context | 重教轮把上一轮题目+作答+评估注入 generate，针对性补教 |
| 深度契约 | Depth Contract | 出题深度以本轮教学论断（taught_claims）为上限——防"教得浅、考得深" |
| 锚定条目 | Anchor Entry | 当前主题的本体条目，强制进检索与生成上下文（防跑题） |
| 教学弧 | Teaching Arc | core 论断的三层组织（2026-08-23）：概念论断（定义+类比）→ 示例论断（worked example，具体化不算编造）→ 要点论断（条目原文写明的规则换强调形式） |
| 概念辨析题 | Concept Choice | choice 题形态（2026-08-23 重做）：LLM 生成题干 + 陈述句正确项 + 误解干扰项三件套，bigram 词重叠校验；取代旧的"哪组要点属于X"关键词归属题 |

## 资源复用

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 条目化导出 | package_to_entry | `core/deliver.py` 纯函数：资源包 → 与知识库 SeedEntry 同构的条目（讲义论断经导出三重过滤：剔 extension/剔学习者指涉含敬语/跨轮换皮去重 0.40，拼接为正文 + 误区段落） |
| 误区提炼 | Distill | `core/agents/distill.py`：从答错记录与脚手架/追问干扰项 + 讲义锚点提炼 0-2 条知识化误区表述（硬性约束 A-F + 锚定校验兜底，无素材短路不调 LLM） |
| 导出条目 | GEN Entry | id 规范 `GEN-{entry_id}-{learner_id}` 的生成条目；keywords 过滤到 content 命中字符；可被 init_db 原样入库——产出物可复用的硬证明 |

## 知识库

| 中文术语 | 英文/代码标识 | 定义 |
|---|---|---|
| 知识条目 | Entry / KnowledgeEntry | 带 id / title / content / keywords / prerequisites / difficulty / knowledge_type / source 的记录 |
| 知识类型 | knowledge_type | `memory`（事实/术语）/ `concept`（概念关系）/ `procedure`（步骤技能），描述本体、不绑定题型 |
| 难度闸门 | Difficulty Cap | 检索时 `max_difficulty` 过滤——beginner 只看难度 1-2 条目 |
| 幻觉率 | Hallucination Rate | 最终裁决为 unsupported 的论断数 / 总论断数（`evals/metrics.py` 唯一口径） |

> **同步规则**：新增/修改术语时，必须同时检查 PRD、架构文档和 AGENTS.md 中对应的用词。
