# 开发约束与工程规范

> 状态：强制。本文档是 `技术选型与架构决策.md` 的执行层，违反文中约束的代码一律驳回。
> 如有正当理由需偏离，必须先修改本文档并注明原因。
> 本文约束同时摘编至仓库根目录 `AGENTS.md`（给 AI agent 读的紧凑版），二者冲突时以本文档为准。

---

## 1. 总则

### 1.1 适用性

- 所有提交到本仓库的代码（含 AI 生成）均须遵守本文约束；
- code review 的唯一检查标准即为本文各条目。

### 1.2 模块化单体原则

本项目的操作模型是一个团队由 AI 为主力 coder 的单人开发。微服务、消息队列、分布式组件在这个模型下是负资产。所有代码必须保持 **模块化单体**：一个 Python 包 + 一个 Next.js 应用 + 一个 SQLite 数据库，再无其他运行态组件。

---

## 2. 技术栈锁定（最高优先级，不可在开发中变更）

| 层 | 锁定 | 版本要求 |
|---|---|---|
| 编排框架 | LangGraph（仅 Python 版，禁止使用 JS 版） | `>=1.0` |
| 后端 | FastAPI + SSE | `>=0.115` |
| 数据库 | SQLite（业务 + FTS5 + sqlite-vec 向量） | FTS5 为 SQLite 内置 |
| Embedding | BGE-M3（sentence-transformers） | 本地，无 API 依赖 |
| LLM 接入 | `core/llm.py` 统一入口：AsyncOpenAI client，用户注入 base_url + api_key | 不预设模型名，不硬编码 provider |
| 前端框架 | Next.js 15 App Router | TypeScript strict |
| 前端样式 | Tailwind CSS v4 + shadcn/ui | 组件必须从 `@/components/ui` 导入 |
| 前端图表 | React Flow（@xyflow/react）+ Recharts | 禁止引入第三方图表库 |
| 交付 | docker compose | api + web + 初始化数据卷 |
| 评测 | pytest | 与工具脚本同源 |
| 环境管理 | uv（Python 依赖）+ pnpm（前端依赖） | 锁文件必提交 |

### 2.1 禁止引入（开发中发现需要以下组件，必须先用非技术方案解决）

- ❌ 消息队列（RabbitMQ / Kafka / Redis Stream / Celery）
- ❌ 时序数据库 / 列存 / OLAP
- ❌ 微服务 / 独立 sidecar
- ❌ NestJS / Express / Bun（后端）
- ❌ Vue / Svelte / Angular（前端）
- ❌ Ant Design / Element UI / Material UI（组件库——shadcn 独占）
- ❌ LangGraph JS（Python 独占）
- ❌ Chroma / LanceDB / Pinecone / Weaviate（向量检索 SQLite 全家桶独揽）
- ❌ Electron（进入缓冲周之前禁止接触）

**新依赖准入流程**：先在本文档 2.1 节申请→注明理由与替代评估→核心拍板→更新本文档→再安装。

## 4. 架构约束

### 4.1 信息流方向（最重要的约束）

```text
api/  ←── SSE ──→ web/
  |                 
  v                 
core/  ── state 流 ──
  |
  v
data/  (SQLite)
                          LLM API (外部)
```

- `core/` 不接触网络层（FastAPI/SSE），只操作 state 和调 LLM provider；
- `api/` 是薄层，不做业务逻辑，只做序列化 → 转发 → 推流；
- `web/` 不写业务逻辑，只消费 SSE 和渲染；
- 数据存储：只有 `data/knowledge.db` 一个文件，禁止散落 JSON 配置文件做数据存储；

### 4.2 Agent 上下文隔离规则（防幻觉架构的代码级约束）

- **诊断 Agent**：state 只注入 `{learner_profile, test_results}`，禁止注入知识库条目原文；
- **生成 Agent**：state 注入 `{retrieved_entries, profile_summary, outline, last_review_feedback}`；须在 LangGraph state 定义中用 `Annotated` 标注仅通过检索获取的 key；
- **审核 Agent**：state 注入 `{draft, cited_entries}`——**禁止注入 learner_profile 的任何字段**（这一隔离是防幻觉机制的核心，也是文档创新性部分的关键论点）；
- **对话日志仅用于画像更新**，永不注入任何 Agent 的生成上下文。

### 4.3 图像数据库约束

- 图编译一次，运行时只调用图形实例；禁止每次请求编译新图；
- 每个节点必须设置 `max_tokens` 上限（via prompt trimming 或 provider config）；
- 辩论轮次硬上限 = 3，超过后走降级策略（仅保留已通过论断重组）。

## 5. 编码规范

### 5.1 Python（core/ + api/ + evals/）

```python
# ✅ 必须
Python 3.11+
所有 agent 间消息使用 Pydantic BaseModel 或 TypedDict
LangGraph StateGraph 使用 Annotated 定义 reducer
LLM 调用统一走 provider 抽象层，禁止直调 openai.ChatCompletion
日志使用 structlog，输出 JSON 格式（供 SSE 解析）
错误处理：自定义异常类 + FastAPI exception handler 统一兜底

# ❌ 禁止
裸 dict 做 agent 间通信
print() 做日志
裸 try/except 吞异常
在 core/ 中调 openai 或任何 HTTP client 直连
使用 threading（用 asyncio）
```

**参考模式：Pydantic 强制类型**

```python
# core/state.py
from typing import Annotated, TypedDict
from langgraph.graph.message import add_messages

class ReviewNote(BaseModel):
    claim_index: int
    verdict: Literal["supported", "partially_supported", "unsupported"]
    reason: str
    suggestion: Optional[str] = None

class AgentState(TypedDict, total=False):
    learner_id: str
    profile: dict
    gaps: list[str]
    retrieved: list[dict]
    draft: list[dict]            # 生成稿：论断列表
    review_round: int            # 辩论轮次
    review_history: list[ReviewNote]  # 辩论链
    final_resources: dict
    assessment_results: dict
```

### 5.2 TypeScript（web/）

```text
# ✅ 必须
TypeScript strict（tsconfig strict: true），禁止 any
use client 仅用于交互组件（onClick、useState、SSE 订阅）
服务端组件优先（async RSC 做数据初载）
shadcn 组件必须从 @/components/ui 导入，禁止绕过
Tailwind class 无序 → class 用 cn() helper 合并

# ❌ 禁止
any 类型
useEffect + fetch（使用 TanStack Query 或 RSC async）
内联样式 / CSS Module（Tailwind 独占）
在服务端组件中写 onClick
直接 import React Flow 的默认导出（用 @xyflow/react）
```

### 5.3 通用

- 所有文件使用 UTF-8 编码；
- 代码注释：只在非显而易见处加（为什么要这样做，不是做了什么）；API 文档用 docstring；
- 禁止注释掉的代码块——直接删除，git 历史可追溯。

## 8. AI 开发协作约定

本节专门约束 AI agent（opencode / Claude Code / Cursor）的生成行为。违反本节约束的代码会被要求重写。

### 8.1 必须遵守

1. **严格按照本仓库目录结构生成代码**：新文件必须放在对应目录，禁止在项目根目录创建源码文件；
2. **新依赖必须先问再装**：任何 `pip install` / `pnpm add` 之前必须在对话中说明理由并等待确认（已在禁止清单里的直接驳回）；
3. **错误必须暴露，禁止静默降级**：try/except 必须记录日志 + 返回结构化错误，禁止 `pass`；
4. **图编译一次，运行时复用**：禁止每次请求 new StateGraph + compile；
5. **生成 Agent 输出必须挂 evidence_ids**：输出 schema 中每条论断的 `evidence_ids` 为必填字段；
6. **审核 Agent 上下文不得包含 learner_profile**：代码审查检查项。

### 8.2 建议遵守

- 新文件写好 → 立刻写对应的 pytest，不要"稍后补"；
- TS 端先定义类型再写组件（TypeScript 的 `interface` 或 Zod schema）；
- Python 端先定义 Pydantic model 再写函数。

### 8.3 AI 常见错误模式（见到以下模式直接拒绝）

| 错误模式 | 说明 |
|---|---|
| 一上来就写 docker compose + Redis + Worker | 过度架构，参考 §4.3 模块化单体 |
| 导入 `@anthropic-ai/sdk` 或 `openai` 然后直调 | 必须走 provider 抽象层 |
| 创建 `server/` 目录放 Express | 本项目只有 `api/`(FastAPI) |
| 写 `useEffect(() => { fetch(...).then(...) }, [])` | TanStack Query 或 RSC 替代 |
| 在 core/ 里导入了 `fastapi` 或 `starlette` | 依赖方向错误 |
| 新装一个向量库替代 sqlite-vec | 已在禁止清单 |
| 把 3 个 Agent 都写在一个 `.py` 文件里 | 一个 agent 一个文件 |
| 给审核 Agent 注入了 learning_profile | 违反上下文隔离 |

## 10. 附录：关键参考模式

### A. Provider 抽象层（所有 LLM 调用的唯一入口）

```python
# core/llm.py
from openai import AsyncOpenAI

class LLMProvider:
    def __init__(self, config: dict):
        self.client = AsyncOpenAI(
            base_url=config["base_url"],
            api_key=config["api_key"]
        )
        self.model = config["model"]

    async def chat(self, messages: list, **kwargs):
        return await self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            **kwargs
        )

# 全局单例，graph 编译时注入
provider = LLMProvider(settings.llm_config)
```

### B. SSE 推送（api/ → web/）

```python
# api/routes/sse.py
@router.get("/stream/{run_id}")
async def stream(run_id: str):
    async def event_generator():
        async for event in graph.astream_events(initial_state, run_id=run_id):
            yield f"data: {json.dumps(event, default=str)}\n\n"
            await asyncio.sleep(0)
    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

### C. FTS5 + sqlite-vec 混合检索（core/retrieval.py）

```python
async def hybrid_search(query: str, top_k: int = 5, alpha: float = 0.5):
    # FTS5 关键词
    keyword_results = await fts5_search(query, limit=top_k * 2)
    # 向量语义
    query_embedding = bge_m3.encode(query)
    vector_results = vec_search(query_embedding, limit=top_k * 2)
    # RRF 融合
    fused = reciprocal_rank_fusion(keyword_results, vector_results, k=60)
    return fused[:top_k]
```

### D. 图像装配入口（core/graph.py）

```python
from langgraph.graph import StateGraph, START, END
from core.state import AgentState
from core.agents import diagnose, generate, review

def build_graph():
    graph = StateGraph(AgentState)
    graph.add_node("diagnose", diagnose)
    graph.add_node("generate", generate)
    graph.add_node("review", review)
    graph.add_edge(START, "diagnose")
    graph.add_edge("diagnose", "generate")
    graph.add_conditional_edges("review", route_after_review, {
        "pass": "deliver",
        "retry": "generate",
        "degrade": "deliver"
    })
    return graph.compile()
```
