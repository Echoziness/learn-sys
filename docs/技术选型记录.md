  同体系标准，职业编码 2-02-10-09，30-50 条切片。

### 2.2 依据

| 维度 | 大数据分析（选定） | 软考软件设计师（落选） | AI 应用集成（降为切片） | 1+X Web 前端（出局） |

| 条目式友好 | 方法体系边界清晰（SQL/统计/算法） | 考纲即条目，最优 | 概念+流程混合，工程文本松散 | — |

## 3. 技术栈选型

### 3.1 定型总表

| 层 | 选型 | 关键理由 |
|---|---|---|
| 编排框架 | **LangGraph Python ≥1.0** | 见 3.2 |
| 后端 | **FastAPI + SSE** | SSE 单向推送图执行事件，比 WebSocket 实现量减半 |
| 存储 | **SQLite 全家桶**：业务表 + FTS5 全文 + sqlite-vec 向量 + RRF 融合 | 单文件 DB、零外部依赖、评委环境零额外组件 |
| Embedding | **BGE-M3 本地**（sentence-transformers） | 检索栈全离线；评委只需一个 LLM key；批量评测零成本 |
| LLM 入口 | `core/llm.py` → **AsyncOpenAI client**，base_url + api_key 注入 | 不预设模型名，不硬编码 provider |
| 前端 | **Next.js 15 + TS strict + Tailwind v4 + shadcn/ui + React Flow + Recharts** | AI 语料收敛栈 |
| 交付 | **docker compose** | 比赛交付标准形态 |
| 包管理 | Python → **uv** · JS → **pnpm** | — |

### 3.2 编排框架：LangGraph Python（否决 JS 版）

**证据**（2026-07 检索）：

- LangGraph 1.0 于 2025-10 GA；Klarna/LinkedIn/Uber/Replit 生产在用，token 开销为三大框架最低（+9%）
- **AutoGen 已死**：微软转入维护模式；CrewAI 无持久化只适合原型
- **JS 版 parity 差距是实坑**：GitHub issue #1767 — `createAgent` 在 JS 版无法作为 StateGraph 节点，官方 1.0 核心组合模式在 JS 侧不成立；月下载 LG.py 4.3M vs LG.js 1.8M

**结论**：本项目创新核心是自定义图逻辑（辩论回路、子图、条件路由），重度使用 parity 差距所在的高级特性。

### 3.3 模型策略

统一走 **OpenAI 兼容协议**，provider 抽象层切 base_url + api_key + model 即换模型。内部实现为 `AsyncOpenAI` client，不做二次封装厂商 SDK。环境变量注入，不预设模型名。

### 3.4 否决记录

| 方案 | 否决原因 |
|---|---|
| AutoGen | 2026 年已处维护模式，无新功能 |
| CrewAI | 无持久化层，工作流中途失败须从头重跑 |
| Chroma / LanceDB / Pinecone | 引入第二个存储组件；SQLite 全家桶可单文件承担全部检索 |
| LangGraph JS | 见 3.2 |
| Streamlit / Gradio | 调度可视化+学情报告+资源排版三画面需求超出其布局能力 |
| Chainlit | 2025-05 创始团队退出；2025 底曝两个高危漏洞 |
| FTS5 trigram 分词器 | **实测排除**：2 字中文词会静默匹配全表，比 unicode 的"单长 token 无法子串匹配"问题更危险 |
| 微服务 / 消息队列 | 单人项目最大隐性风险：过度架构 |

### 3.5 知识库内容来源

1. 标准 PDF（政府官网公开）→ 条目骨架：职业功能 / 工作内容 / 相关知识要求直接映射
2. 条目正文：SQL/pandas 官方文档 + 经典教材的理解性改写（禁直接复制，版权合规）
3. 每条标注 `source` 出处，溯源链直通官方文档

## 4. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| AI 生成代码过度架构 | 高 | AGENTS.md 明令模块化单体、禁微服务/MQ；新依赖须先记录理由 |
| sqlite-vec AI 语料密度低 | 中 | 手写 30 行参考实现定 pattern，AI 照抄；检索层封装抽象接口可换 Chroma |
| LangGraph 高级特性坑 | 中 | W1 先技术验证；只用官方文档确认过的 API |
| 知识库进度拖期 | 高 | 种子条目 15 条先支撑链路；后续 AI 批量草稿 + 脚本自动校验 |
| 评委环境无法跑 LLM API | 中 | docker 内置预生成运行记录，支持"回放模式"演示 |
